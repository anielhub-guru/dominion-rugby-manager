# Dominion artwork workflow

For any request involving player hairstyles, head styles, headgear, avatar appearances, silhouettes or related image transformations, read [`docs/avatar-silhouette-pipeline.md`](docs/avatar-silhouette-pipeline.md) before editing. A new player hairstyle normally requires coordinated work in the Avatar page, both Silhouette Lab previews and Dominion League; do not stop after updating only one surface.

# Commits

Do not add a `Co-Authored-By` trailer or any other Claude attribution line to commit messages or pull request descriptions.
